## 操作与未验收边界

- `pnpm ops:setup`生成本机健康令牌与`.env.health.local`，不打印令牌，不启用对外消息。
- `pnpm ops:health --once`独立检查；当前缺少G02/G03/G04及生产备份时返回未就绪是预期结果。
- `pnpm ops:restore-drill`只允许agri_test角色，生成独有schema并恢复同一schema；不会停止项目数据库容器、触碰agri_dev或覆盖public。
- 生产G06还需确切备份方式、WAL连续归档或托管恢复链、存储/NAS权限与取回方法、执行人员、资源费用、独立通知通道和真实数据量演练。生产恢复操作卡须据这些交付写定，当前本地命令不能代替。

本轮构建目录反复出现带编号的生成文件副本，导致Turbopack持久缓存损坏及重复类型声明。已依据安装版Next文档关闭开发/构建的文件系统持久缓存，并仅在TypeScript中排除`.next/types`和`.next/dev/types`中的带空格副本；规范命名的生成校验器和全部src测试仍参与类型检查。没有修改外层网站配置或关闭应用类型检查。
