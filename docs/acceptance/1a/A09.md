# A09 维护、人工复测、工单与导出

已实现清洁、校准参数、更换、安装基准调整和维修记录；记录实际发生时间、依据与人员，更正使用supersedes_id追加。校准须有参数名称、原值、调整值与单位。手持复测独立存储，原始读数与可比较数值分开，不覆盖或平均在线数据。维护/复测均进入同一测点历史页面。

故障工单从登记到人工指定人员、处理、专业复核，分别校验record/dispatch/review权限；登记故障不自动派发。处理及复核事件留痕。

导出以JSON保留对象/测点/批次/规则/绑定/告警/维护/复测及更正关系，数值单位和原始时间随记录保留。原报文仅导出引用、SHA-256和大小，避免一份共享报文带出范围外内容；完整原始字节通过数据库备份保留。范围外父对象/父设备及人员ID是外部引用，不自动带出未授权资料。最多20个对象、31天测值、每类5000条和8MB，超限明确拒绝，不静默截断。

导出快照存于受控数据库，下载有效期初始设为24小时，下载时再次验证当前账号和每个对象的export授权，撤权后旧文件也拒绝下载。规范化JSON排序保证存入数据库后重新下载的字节哈希一致；不生成可绕过鉴权的公开文件URL。

新增3项数据库测试通过：更正保留原值、维护/复测并列及在线值不变；导出关系与哈希、撤权及其他账号拒绝；工单的人工安排、指定人员处理和专业复核。所用记录全部标注为合成练习，真实维护或现场确认的练习还需A11签认。

到期后禁止下载；物理清理与数据保存期限仍待生产留存策略确认，未把链接到期等同于已销毁数据。
