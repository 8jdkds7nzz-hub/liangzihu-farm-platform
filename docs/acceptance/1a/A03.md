# A03 原报文、去重与冲突

本地核心已实现：原始字节/接收时间/SHA-256、凭据字段拒绝归档、来源/设备/测点/指标/记录身份去重；同身份不同内容保留双方与冲突记录；当前投影引用冲突值时降为待核。原报文与测值有数据库禁止更新/删除的约束。重放报文与同一观测保持关联。

采集批次锁定自身来源，原报文、测值、事件、任务与游标同一事务；失败完整回滚，旧游标不能覆盖新进度。合成测试已验证并发重放、有效零、无效零、旧数据、未核实映射、游标回滚及冲突。G02实时适配与真实回放尚未验收，见接口契约。
