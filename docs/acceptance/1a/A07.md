# A07 通知状态与夜间升级

> 本文为原阶段历史记录；2026-10-02软件补齐后的当前状态见[一期总交付](../../releases/2026-10-02-一期软件补齐交付核对.md)，原未实施描述不覆盖本轮代码与实测。真实生产仍未验。

本地业务状态机、值班/联系人配置接口、通知规划进程及替身测试已实现，真实企业微信/电话仍未验收。

值班按对象与时段登记，防时段重叠；人员须启用、有对象权限且职责角色匹配。联系方式加密保存，读取配置仅显示“已登记”及核实状态。首次实际发起通知时写first_notification_at，重试不重置。

自动测试覆盖179999/180000毫秒边界、非夜班、认领停止、同租约并发只调用一次、受理后丢失回执不重发、无提供商编号保留未知、已接通不算认领、顺序升级以及已排队电话在认领后取消。记录送达、接通、认领分别存在不同表，不相互推定。

通知执行器默认仅规划，不领取真实发送任务。实际send/query接口只能由已核实的厂家适配器实现；当前wecom/voice提供器显式返回未就绪，不联系真实人员。实际模板、测试号码、呼叫时限、回执验签与计费资料见G03/G04缺口；恢复未知回执、预算及健康检查在A10/A11整体验证。

通知执行循环支持显式注入提供器，已用替身验证自动发送与持久查询任务消费；无提供器时仍只规划。查询得到未知不重发原发送，已确认受理事实保留；可核实结果可结束对应待核发送工作。真实提供器及回调验签仍待G03/G04。
