# A00 独立项目与可重复测试环境验收

核验日期：2026年10月1日。范围为本地开发基座；A01及之后的身份、设备、采集和告警功能尚未开始。

## 项目与环境

- 本地目录：`智能体整体方案/智慧农业平台/`，独立Git及pnpm工作区。
- 私有远端：[liangzihu-farm-platform](https://github.com/8jdkds7nzz-hub/liangzihu-farm-platform)，已核实`isPrivate=true`。
- Node.js 25.9.0、pnpm 10.33.0；项目要求Node至少22.15.0。
- Next.js 16.3.8、React与React DOM 19.2.4、pg 8.23.0、TypeScript 5.9.3、tsx 4.23.15，依赖和锁文件均在本仓库。
- 项目专属PostGIS容器：PostgreSQL 18.6、PostGIS 3.6.4，镜像摘要与linux/amd64平台固定在`ops/compose.yaml`。
- 开发库`agri_dev`和测试库`agri_test`使用独立角色，端口55432，仅监听本机。原有主机数据库未迁移或修改。

## 实施调整

1. 最初按计划的16.2系列安装16.2.12；实际审计报告Next.js及其依赖存在已披露问题，因此升级到16.3.8，重新阅读当前版本路由文档并复跑测试、类型检查和构建。最终生产依赖审计未报告已知漏洞，该结果仅限本项目依赖及本次查询时点。
2. 主机PostgreSQL未安装PostGIS，全局安装会升级较多现有依赖，已停止；采用独立容器，未升级主机现有数据库。
3. 嵌套目录需要独立pnpm边界。已设置本项目`pnpm-workspace.yaml`、独立锁文件和Turbopack根目录，清理初次安装产生的外层子项目锁条目，保留外层原有修改。
4. 仅登记已实现的脚本；采集与通知worker命令随对应工作项加入，不创建空壳worker。
