# A06 规则、告警与认领

已实现规则草稿版本、专业审核与启停。规则须关联已核实的对象/测点/物种阶段批次，保存单位、比较方式、阈值、持续时长、时效和依据。未审核不允许启用；新版本启用前须处理旧版本未关闭事件。管理员的configure不代替review。

告警执行器按新样本推进，重复旧值不延长计时，缺口、无效值或版本切换打断候选计时。测值恢复只转“恢复待关闭”；复发、继续、数据冲突及缺测分别留痕。过期历史冲突不能无条件打断当前候选。厂家故障按来源与对象合并；监测中断另建现场核查事件，严重等级不由程序猜测。

现场核查与排障分别认领，事务和唯一索引防双重认领；幂等标识冲突拒绝。工人认领现场核查、维护人员认领排障，技术员/负责人按授权参与。核查和处置均追加记录；关闭须引用本事件两类记录，未恢复事件只有专业审核为误报才能关闭。未知分类不能关闭。

新增规则纯函数测试与数据库闭环测试通过：审核门控、持续计时、旧值/单位、缺口、版本、开警去重、两人竞争、重复请求、恢复不自动关闭及缺测检查。`worker:alarms`拥有独立2连接默认预算，以任务类别消费事件，扫描监测中断；尚未启动生产告警值守。

本轮只用明确标为合成的阈值与批次测试。G05正式阈值/时效/夜班时段、G01真实批次与责任人仍待交付。真实电话与推送不在本项结果中。
