# A05 持久任务与恢复

已实现queued/running/retry_wait/awaiting_receipt/done/failed状态、业务唯一键及内容冲突检查、优先级、按kind领取、SKIP LOCKED行锁、租约令牌、尝试历史及处理版本。业务事件与任务一同提交；事件消费以consumer和event_id防重复。

合成数据库测试通过：两执行者并发仅一个领取；过期/旧令牌不能完成；未开始外部调用的过期任务可恢复；已标记外部调用的过期任务进入awaiting_receipt且普通领取器不再领取；事务失败不留下工作；同一事件处理计数为1。

执行器限定任务类别，独立进程使用各自连接池与并发预算。未知外部调用不能由通用重试器再次发送；真实提供商查询能力及网络回执异常仍须在G03/G04联调。没有承诺网络操作天然只执行一次。
