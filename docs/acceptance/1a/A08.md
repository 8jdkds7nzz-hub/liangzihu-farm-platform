# A08 手机与电脑页面

当前可操作入口：对象台账及详情、设备与测点、历史曲线、告警列表/详情、规则审核、值班安排、人员和设备配置。手机与电脑使用同一API和业务ID。

流程：找到对象→进入测点历史查看采样/上报/接收时间、质量与时效→进入告警→分别认领核查或排障→追加记录→按专业审核及恢复条件关闭。提交期间按钮禁用，关键认领/记录/关闭携带稳定请求标识；后端独立防重和权限检查。失败显示错误，不显示保存成功。

曲线不补零、不跨缺口连线；可疑点单独着色。通信成功与数据过期分别显示，维护标记和人工复测并列，未并入在线测值。历史分页仅代表当前页，界面明确提示。

最终浏览器断网、重复请求、无权访问、跨终端同一事件及手机/桌面截图已通过，具体记录与限制见A11。1a仅在线文本流程，离线与照片未实施。
