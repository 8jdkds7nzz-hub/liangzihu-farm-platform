# B42 机具终端绑定与人工派单

## 设计与任务

来源：[本段设计](../../specs/2026-10-03-四期4b农机服务与费用补贴详细设计.md)、[字段接口](../../specs/2026-10-03-四期4b字段接口与审核约束.md)、[实施计划](../../plans/2026-10-03-四期4b农机服务与费用补贴实施计划.md)。基线沿用总体设计的对象授权、原值保留、事实分层与逐段验证。

## 已完成的软件

机具与终端有生效时段及唯一对应，服务单保存对象、边界、工种、计量和作业窗口；派单由有dispatch权限人员确认。

主要代码：[src/modules/machinery/orders.ts](<../../../src/modules/machinery/orders.ts>)。页面入口：`/machinery`、`/business`。数据关系：`machinery_bindings,machinery_orders`；首次开发不向agri_dev填入合成业务数据。

## 字段、权限与失败处理

machineDeviceId/terminalDeviceId/validFrom/validUntil；订单contractId/bindingId/title/operation/boundary/startsAt/endsAt/quantity/unit/sourceRef。

record建草稿；dispatch确认；绑定设备必须实物已核且同一对象，验收独立于创建及证据提交人。

同一终端/机具有效绑定重叠拒绝，过期合同或解绑不能派单；计划面积不当作实际完成面积。

## 实际验证

并发绑定只能一个成功；未派订单不收实际验收；订单修订追加新版本。

证据入口：[phase4-4b.test.ts](<../../../tests/integration/phase4-4b.test.ts>), [phase4-business-browser.test.ts](<../../../tests/acceptance/phase4-business-browser.test.ts>)。上述测试及恢复脚本已实际执行；截图、采样值、轨迹和凭证都是agri_test隔离schema里的合成样本。未以代码存在代替真实设备验收。

全量241项先通过；补贴实际时间增加1项，四期18项定向回归、科研经费和农机页面补充复核再次通过。独立用例合计242，重复执行不加计。明细见[总交付](../../releases/2026-10-03-四期软件交付核对.md)。
