# 监控与航次原件接入验收

2026-10-02按1b/1c自主设计开发授权，补齐已取得授权下载链接之后的私有原件保存链。不是厂家告警订阅、航次查询、官方图片解密或现场验收；真实外网读取继续关闭。

## 完成内容

- 网页选择已有监控事件/航次文件，明确只读使用权限及已解密文件条件；输入遮蔽链接，不写入浏览器本地持久存储。网络确认丢失按原请求键重试。
- URL通过AES-256-GCM和任务独立AAD加密。列表仅显示任务、目标、公开域名、状态、原件ID和实下载校验值，不返回URL、密文、URL摘要或私有存储路径。
- HTTPS固定域名白名单，逐级跳转检查；全部DNS结果须公网，连接固定已检查IP并验证原域名证书。无Cookie/API授权头/Referer；整次20秒、最多3次跳转、最多20MiB。
- 网络读取在数据库事务之外。入库前后核对发起人身份版本、当前权限、来源契约/核实、设备/对象、目标及任务租约。撤权或改变契约时旧结果不关联原件。
- 监控先建告警和通知任务，下载独立处理；取图失败及后补都不生成第二条告警/通知。航次按已存在的原清单SHA-256核对，异内容失败，不能覆盖清单。
- 实下载文件走既有私有存储复读校验和备份任务。缺拍摄时间保持null；没有厂家SHA-256的监控图片只证明本次实下载与本地副本一致。

- 7项数据库业务测试：幂等与冲突、先通知/后补图、航次校验/换链接、执行前与下载过程撤权/撤回来源/租约/关闭开关、格式失败、结果未知、私有保存期间撤权整体回滚。

## 本机操作

1. 配置管理登记来源并核实接口资料及只读权限；事件关联已核实设备，航次文件有真实原清单校验值。
2. 部署人员核对实际CDN域名后设置MEDIA_IMPORT_ALLOWED_HOSTS，默认MEDIA_REMOTE_READS_ENABLED=0；不得使用通配符。正式启用须完成G07/G08真实授权与样本核对，本轮未启用。
3. 监控与航次页面展开“下载链接转入私有原件库”，选择目标、填原件链接/格式/使用依据并提交。20MiB以外原件不使用此入口。
4. `pnpm worker:media`独立处理下载和备份；查看状态与受控原件。航次“文件完整”和“备份完整”分开显示。
5. 失败/条件不足核对后可提交新链接和新任务；中断结果unknown不自动重读。已有原件不替换，不更改原告警认领/核查结论。

## 联调与回退边界

真实萤石/海康消息签名/权益/机型与加密图片、大疆司空公有云/私有化实际版本、航次查询与完整媒体清单、实际CDN、原件体积、NAS/私有桶/异地备份、现场终端尚未验证。大航次视频/正射通常可能超过当前上限，须按真实规模补齐分段或流式入库后验收；本轮不签大型成果全链路完成。

停止读取可将全局开关设0并重启media worker；已排队请求会明确停止处理。回退使用上一构建、保留022表与已入库原件，不逆迁移删除记录。若权限在私有保存期间撤回，事务回滚且无可下载的媒体记录，私有存储可能留无公开引用的字节，后续清理必须核对完整引用，不能按失败状态删已共享原件。
