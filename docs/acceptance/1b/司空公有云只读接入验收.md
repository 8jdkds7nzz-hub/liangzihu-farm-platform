# 司空公有云只读接入验收

2026-10-02继续自主完成1b接入。指定任务UUID的公有云V2任务/媒体快照、支持原件的私有入库与备份、人工确认实际航次已形成完整软件链。没有调用实际司空账户，没有开飞行、调度、控制、删除或Sync设置。

## 本轮能力

- 固定公有云示例域名和两个GET路径，带X-User-Token/X-Project-Uuid；不跟随接口重定向、不接受网页令牌输入。令牌只在私有环境，原件CDN不会收到它。
- 连接首次停用，来源/机场/项目有版本与证据。任务请求键防重、同键异参数冲突；网络前后复核授权、身份、来源契约、机场SN、配置与租约。
- task详情begin_at/end_at仅作计划时间；API未提供实际时间不代填。媒体create_at/update_at不代拍摄时间。原件captured_at保持null。
- 每次明确读取保留独立快照。公开metadataHash排除临时URL，不把签名刷新当文件变化；这个摘要不证明影像内容相同。接口原响应和原件URL加密归档，有原字节SHA和关联。
- 按实际HTTP阶段的服务器时间记录尝试，跨月分别记用量。未知单价保持null。月限额包含排队预留；失败/变更/运行中断保持明确状态，结果未知不自动重发。
- 文件经大小/格式/实下载SHA、私有复读后确认；备份进程复制和再读后单列verified。0字节、未知类型、PPK/模型、缺链接和超过20MiB不假装已入库。
- 所有快照文件完整后，技术员核对实际航次ID、真实起止、实际飞行器、机场、坐标/垂直基准和单次文件归属，再复用既有航次/原件关联。不是用计划任务生成一次真实飞行。快照已确认后不改关联至另一航次，实际信息变更也不能覆盖旧航次。

## 使用步骤

1. 配置管理登记并核实dji_fh2_public_v2来源、实际机场/飞行器、SN和型号；技术员需本对象read/record，配置者需configure。管理员本身不自动获得业务record动作。
2. “监控与航次→司空公有云只读任务与原件”登记项目UUID、已核实机场、许可依据及月请求上限。初建停用，明确确认后启用连接。
3. 私有部署环境为`DJI_OPENAPI_READS_ENABLED=0`；实际组织密钥放`DJI_OPENAPI_TOKEN`，本轮未配置。当前实现只访问官方KeyCenter示例中的`es-flight-api-cn.djigate.com`，区域/账户实际域名须G08验证后再启用，不能沿用官网示例令牌。
4. `pnpm worker:flighthub`处理明确请求。输入taskUUID读取快照，核对厂家状态、计划时间和预期/已上传/返回资源数。查看成功/空数据/失败/条件变化/未知状态。
5. 原件下载还需独立`MEDIA_REMOTE_READS_ENABLED=1`及精确已核实CDN域名；真实读取本轮均关闭。只保存支持格式20MiB以内文件，`pnpm worker:media`继续校验备份。过期链接重新取快照，不覆盖旧URL/快照。
6. 核实“当前清单只属于这个实际航次”，独立填写实际时间/航次ID/设备与基准。任务未结束、清单有缺口、文件未完整或超过现有航次500文件上限时不能签完整。达到API10000条上限不声明完整；网页最多展示1000资源、100快照，后端确认仍检查所选快照全量。

回退关闭读取/下载开关、停止新增worker、使用上一构建并保留024表/原件；不逆迁移删数据。工作区已有登录简化修改保持其原内容，本轮另做干净基线验证并限定提交。
