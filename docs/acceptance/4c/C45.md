# C45 七类综合指标与输入快照

## 设计与任务

来源：[本段设计](../../specs/2026-10-03-四期4c科研试验与综合指标详细设计.md)、[字段接口](../../specs/2026-10-03-四期4c字段接口与计算约束.md)、[实施计划](../../plans/2026-10-03-四期4c科研试验与综合指标实施计划.md)。基线沿用总体设计的对象授权、原值保留、事实分层与逐段验证。

## 已完成的软件

按明确对象和时间窗列设备、作业、质量、调度、经营、服务、风险七组指标；已知数量/分母、未知和缺项同时展示；不建展示大屏。

主要代码：[src/modules/management/calculate.ts](<../../../src/modules/management/calculate.ts>)。页面入口：`/research`、`/management`及固定协议/结果/报告页面。数据关系：`management_reports`；首次开发不向agri_dev填入合成业务数据。

## 字段、权限与失败处理

objectId/fromAt/toAt/sourceRef；窗口最长366天；固定白名单SQL及定义版本，输入引用和结果快照保存；不接受任意SQL。

read读取当前对象，record生成报告，export导出；专家只读明确分享的固定报告。

零分母不报100%，空库不报运行正常；超过输入上限拒绝；当前授权变化后旧报告重新鉴权。
