# A41 能源设备与计量档案

## 设计与任务

来源：[本段设计](../../specs/2026-10-03-四期4a能源与循环物料详细设计.md)、[字段接口](../../specs/2026-10-03-四期4a字段接口与计量约束.md)、[实施计划](../../plans/2026-10-03-四期4a能源与循环物料实施计划.md)。基线沿用总体设计的对象授权、原值保留、事实分层与逐段验证。

## 已完成的软件

设备与已有物理设备对应；用途区分发电、负载、储能，记录型号、额定容量、计量倍率、周期与来源，未核状态可登记但不参与正式统计。

主要代码：[src/modules/energy/service.ts](<../../../src/modules/energy/service.ts>)。页面入口：`/energy`、`/circular`。数据关系：`energy_meters`；首次开发不向agri_dev填入合成业务数据。

## 字段、权限与失败处理

objectId/deviceId/name/purpose/capacityKwh/maxGapSeconds/sourceRef；设备须属于当前对象，容量未知为null，间隔为专业登记值。

configure负责建档，review独立核实；绑定不改变原设备或测点身份。

伪造设备对象、负间隔、未核观测拒绝；相同提交标识返回原记录。

## 实际验证

创建档案→独立核实→追加观测；其他对象设备不能关联。

证据入口：[phase4-4a.test.ts](<../../../tests/integration/phase4-4a.test.ts>)。上述测试及恢复脚本已实际执行；截图、采样值、轨迹和凭证都是agri_test隔离schema里的合成样本。未以代码存在代替真实设备验收。
