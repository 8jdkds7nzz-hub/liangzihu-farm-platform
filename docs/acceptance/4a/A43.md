# A43 循环物料批次与接收称量

## 设计与任务

来源：[本段设计](../../specs/2026-10-03-四期4a能源与循环物料详细设计.md)、[字段接口](../../specs/2026-10-03-四期4a字段接口与计量约束.md)、[实施计划](../../plans/2026-10-03-四期4a能源与循环物料实施计划.md)。基线沿用总体设计的对象授权、原值保留、事实分层与逐段验证。

## 已完成的软件

循环物料共用stock_lots、stock_documents和质量放行；登记来源批、物料类别、接收地及检测依据，称量区分毛重、皮重、净重、湿干基及含水率。

主要代码：[src/modules/circular/service.ts](<../../../src/modules/circular/service.ts>)。页面入口：`/energy`、`/circular`。数据关系：`circular_batches,circular_weighings`；首次开发不向agri_dev填入合成业务数据。

## 字段、权限与失败处理

lotId/materialKind/originRef；weighing含grossKg/tareKg/netKg/moisturePct/basis/occurredAt/voucher；净重必须等于毛减皮，干物质量为辅助记录。

record按对象授权；已有批次须kg且口径一致，不能复制同一批为两份库存。

毛重小于皮重、称量与过账数量不符、跨对象仓位、重复凭证冲突；未知含水率不估算干重。
