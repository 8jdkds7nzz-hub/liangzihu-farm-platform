# 四期4A字段接口与计量约束

本页补充[4A详细设计](2026-10-03-四期4a能源与循环物料详细设计.md)，以本次实际API为准。所有写入使用POST、同源校验、当前会话及对象授权，并携带稳定`requestKey`；共用页面还携带原账号请求头，防止换号误提交。

## 能源档案

| API | 主要输入 | 约束与结果 |
|---|---|---|
| `/api/v1/energy/meters` | objectId、deviceId、name、purpose、capacityKwh、maxGapSeconds、oxygenPointId、sourceRef、supersedesId | purpose为generation/load/storage；容量未知留空；间隔1—604800秒；设备同对象且为物理设备；参考测点须已有同对象有效绑定 |
| `/api/v1/energy/reviews` | id、action、evidence | approve/withdraw；独立人员有review权限；物理设备及对象对应未核实不能核实通过 |
| `/api/v1/energy/readings` | meterId、metric、value、observedAt、quality、reset、sourceKind、operatingState、alarmNote、evidence、supersedesId | 原值追加；同一指标时点的修订须引用当前记录；新档案版本独立审核，不沿用旧批准 |

`metric`仅接受累计发电/用电/充电/放电kWh、功率kW、SOC百分比、SOH百分比。`quality`为valid/suspect/missing；有效值不得为空，百分比0—100。`sourceKind`为manual/file，明确这是人工记录或文件抄录，不宣称厂家实时HTTP已接入。`operatingState`为charging/discharging/idle/unknown，缺失默认unknown。

录入使用已核换算后的标准单位。原始值、原单位、倍率、型号和校正依据写入sourceRef/evidence；系统不自行猜测厂家倍率。maxGapSeconds由专业资料确定，没有默认“全场都适用”的采样间隔。

能源档案、审核事件与观测分别落表。档案用版本和supersedes_id修订，审批事件不可改写；旧观测继续可查。原件文件和模型权重不随能源记录复制到public目录。

## 区间计算

`GET /api/v1/energy/summary?meterId=...&metric=...&fromAt=...&toAt=...`只接受四种累计kWh指标，最大366天、10000条当前版本观测。返回输入ID、原始观测、定义版本、实际范围、完整结果及缺口。

- 区间起止须恰有对应观测；没有边界时不外推整段耗电。
- 相邻有效观测不超过已核间隔且未复位，才计算`本次累计值−前次累计值`。
- 表值倒退、reset、可疑/缺失值或超长间隔均断开该段。
- `energyKwh`只有全部条件满足才给值；不完整时为null。`knownSegmentKwh`仅列已知连续片段，不能当全窗口结果。
- 0是合法实测差分，空值不转成0。功率不直接积分成耗电，不自动决定开机或错峰。
- 如关联了溶解氧等环境测点，最多并列31天、500条原观测，保留其单位、质量和数据状态；超过上限显式说明。该参考不触发负载控制。

`GET /api/v1/energy/overview`按objectId读取最近200条；统计入口不使用这一截断列表。`GET .../export`另查export权限。

## 循环物料

| API | 主要输入 | 约束与结果 |
|---|---|---|
| `/api/v1/circular/batches` | lotId、materialKind、originRef | 引用已有kg库存批次，标记silt/manure/straw/mushroom/compost/other，不再创建第二份库存 |
| `/api/v1/circular/receipts` | lotId、locationId、grossKg、tareKg、netKg、moisturePct、basis、voucher、occurredAt、evidence | 净重=毛重−皮重；批次鲜干基必须一致；凭证按对象防重；称量与库存入库同事务 |
| `/api/v1/circular/processes` | objectId、code、processKind、inputs、outputs、occurredAt、evidence、reason | treatment/screening/rework；输入输出各1—20行，每行为lotId/locationId/quantity，全部属于本对象已登记循环批次 |

鲜重与干重不直接混加。湿基/原样有实测含水率时，辅助干重按`净重×(1−含水率/100)`计算并截取至六位小数；未知含水率则辅助干重为null。这个派生量不改变库存的原始口径，也不表示称量有六位精度。干基批次的净重按其已登记干基保存。

处理复用三期stock_documents、stock_entries、stock_transformations和stock_lineage：输入须当前放行，输出须待检；不同口径或存在差额需要review权限和原因。返料新建输出批次，不能形成回到旧批次的环。独立质量放行、问题处置、发货、签收仍在库存与质量模块办理。

## 权限、导出与故障

内部人员按原角色及read/record/configure/review/export授权操作；外部专家不能通过对象overview批量读取。更正、审批和数量分录保留历史。跨对象设备、仓位、批次或测点一律拒绝。

能源、循环物料的模块导出上限各为5000行/表、8MiB；循环物料与库存合并后仍受8MiB总上限。统一“资料与关系”导出也包含三四期数据，并列出未选择的跨对象资料和角色限制。

字段错误400/422，权限403，版本/凭证冲突409，容量413。网页保留错误输入，部分导入失败不清表单；未知外部结果不自动重发。恢复验证覆盖6张4A新表、实际库存分录和质量关系。真实能源协议及硬件验收见G16。
