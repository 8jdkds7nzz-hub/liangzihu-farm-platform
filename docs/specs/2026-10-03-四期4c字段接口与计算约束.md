# 四期4C字段接口与计算约束

本页补充[4C详细设计](2026-10-03-四期4c科研试验与综合指标详细设计.md)。科研协议、原始观察、人员成果说明和统计结果分别保存，不自动判断农艺因果。

## 科研协议与观察

POST前缀`/api/v1/research/`。GET overview使用objectId，protocol/result使用固定记录id；export单独验证导出权限。

| section | 主要字段 | 约束 |
|---|---|---|
| protocols | objectId、title、question、baseline、plots、metrics、startsAt、endsAt、testingPlan、stopRules、sourceRef、supersedesId | 2—20小区，1—20指标；必须有不同对象的处理和对照；保留对象版本及边界状态 |
| reviews | id、action=approve/withdraw、evidence | 独立人员核实；旧版本不得再次批准为当前版本 |
| observations | protocolId、plotObjectId、metric、sampleKey、value、observedAt、method、kind、agency、reportRef、missingReason、evidence、assetIds、supersedesId | 当前已核协议；小区read/record；方法、单位和窗口一致；原件当前可读 |
| results | protocolId、title、claim、claimLevel、sourceRef | 按协议版本生成实际输入快照与描述统计，最多5000条/8MiB |
| result-reviews | id、action=approve/withdraw、evidence | 独立于结果创建及所用观察的提交人；依据变动后不能沿用旧输入批准 |

每个plot包含objectId、label、group=control/treatment和可选batchId；批次必须属于相应小区。每个metric包含code、name、unit、method、expectedSamples，code使用小写字母/数字/下划线，计划观测条数1—100000。小区有未知边界时可以登记，但不用于面积精度结论。

sampleKey是同协议、小区、指标下的稳定观察号。更正明确引用当前版本；原值、原时间和理由保留。值允许正负十进制数，最多六位小数；未知为null且必须说明原因，0只有明确观测时填写。

kind为field或lab_report。第三方报告需机构、编号版本和至少一份已完整入库的私有原件；记录这些字段不代表系统已经核验证书或机构真实性。

## 结果与经费

结果保存完整协议和当时采用的当前观察行、输入哈希、计算定义版本。按小区与指标列记录数、数值数、计划缺口、均值、最小和最大；均值按六位小数截取。观测条数不等于独立试验重复数，不自动计算显著性或判定增产。

claimLevel分为verifiable（可核实）、official（官方口径）、self_reported（自报）。正文必须说明来源和限制。观察更正或协议撤回后，旧结果保留旧值，并显示sourcesCurrent=false；旧审核记录也保留，不把历史审核标记当作当前依据仍有效。

经费复用4B business_expenses和expense_payments，用linkKind/linkId关联协议或结果。科研页只给有财务角色的用户显示费用；专家固定结果不自动获得费用、其他小区页面或原件下载权限。

## 综合指标与后台任务

`POST /api/v1/management/reports`接收objectId、fromAt、toAt、sourceRef、requestKey，返回排队记录。`worker:management`独立处理management.calculate任务，数据库连接上限为2。

生成主体与authVersion随任务保存。任务开始及提交结果前分别检查当前权限、身份版本与租约；过期租约不能写回。读取输入使用一致数据库快照，结果完成后不可覆盖；新计算产生新记录。中断任务通过持久队列重新领取，失败显示原因。

同一人员最多5份待处理报告，额度检查与入队加锁防并发绕过。窗口最多366天；每类输入5000条，当前服务验收关系最多500项，计算读取阶段10秒预算、结果8MiB上限。超限明确要求缩小范围，不用前台最近200条代替统计。

| 指标组 | 已实现口径 |
|---|---|
| 设备与采集 | 生成时已登记/已核设备，窗口内规范观测数、有效观测数及两者之比 |
| 作业 | 窗口内当前版本农事记录和已审核记录数 |
| 质量 | 窗口内报告与未通过报告记录、生成时未结质量问题 |
| 调度 | 生成时任务、待复核、逾期和缺期限记录 |
| 经营 | 窗口内费用条数、已知登记金额、未知金额数、人工登记净实付 |
| 服务 | 窗口内计划服务单、当前依据仍有效的验收、已取消单 |
| 风险 | 生成时未关闭告警、严重告警和未结质量问题记录 |

有效观测占比不等于设备在线率，也不等于应采样完整率。零分母为null；零告警不等于现场无风险；无金额不视为0成本。Now类字段是生成时点状态，其余按开始包含、结束不包含的窗口取数。没有收入等完整账目，不生成利润或节能收益结论。

## 分享、导出与旧版本

research_protocol、research_result、management_report以固定ID授权。外部专家只能访问明确分享的固定资料，不能通过overview浏览对象全历史；到期和撤回立即影响后续读取。照片和检测报告仍需要独立媒体授权。

内部读取试验结果还检查各小区read权限；整包导出同时检查各小区export权限。统一导出仅包含本次显式选择的全部小区都在范围内的试验；未包含的跨对象资料有排除说明。

管理报告含经营信息，内部读取/生成/导出受财务角色及对象权限限制；专家仅从明确分享的报告入口读取。缓存导出重新核对当前角色和对象授权。

完整交付包含六张4C新增表、追加的跨账号导入身份表042、后台任务和私有证据的非空恢复。真实试验方法、专业审核、数据覆盖范围与农业效果由G18签认。
