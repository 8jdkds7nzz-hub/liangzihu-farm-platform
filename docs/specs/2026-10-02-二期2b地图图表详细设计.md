# 二期2b地图图表详细设计

## 目标

让人员能找到对象、看清资料状态和时间变化。继续使用一期真实授权图层，不增加公开底图依赖或猜测地理数据。

| 编号 | 行为 | 验收 |
|---|---|---|
| V01 | 地图搜索对象、图层开关显示数量/缺口、选中对象详情与相关业务入口 | 图层只影响呈现，不扩大权限；对象缺边界有明确提示 |
| V02 | 鼠标/触摸平移、按钮/键盘缩放与复位，拖动不误触详情链接 | 桌面与触摸浏览器、键盘和复位实测 |
| V03 | 测点图表有单位/时间轴、可聚焦点详情和质量标记；无效/冲突/缺测断线 | 零值保留，null不补零，未配置间隔只画点，不按压缩显示位置计算时间 |
| V04 | 指标按定义/版本和窗口呈现趋势；不混单位或用旧版本冒充新计算 | 可选定义，撤回/不足显示不可用，来源和限制随图保留 |
| V05 | 图表仍配原值表、二维仍可访问；手机布局及导出/分享权限沿用一期 | 屏幕阅读/键盘/窄屏检查，一期媒体和专家共享回归 |

图表计算只负责坐标和分段，业务指标由原服务计算。纯函数放`src/modules/analysis/chart.ts`，`TimeSeries`仅接收已授权数据，不接任意查询。测点数据超过分页范围时明确“当前已加载区间”，不画完整全期的假象。

地图与三维共享`GET /api/v1/map`对象/设备/覆盖/注记；2B只增加选择和呈现。当前底图基准EPSG:4326，正射必须经过一期配准核对。三维入口位于地图相邻页面，手机不默认加载三维引擎。
