# 监控与航次原件接入设计

用户已授权1b、1c自主设计与开发，沿用已确认设备与范围。本次实现已取得下载链接之后的原件保存链，连接厂家账户、消息订阅或司空航次查询仍按G07/G08办理。没有把公有云、私有化及Cloud API混为一种契约。

## 范围与方案

采用异步下载任务：已核实来源的监控事件或航次文件 → 加密链接任务 → 独立媒体worker → HTTPS下载、SHA-256和格式核对 → 私有原件保存复读 → 关联原事件/航次文件 → 已有备份任务。沿用通知先建、图片后补的顺序。下载失败不改变告警，也不增加通知。

另两种路径是浏览器下载后手工上传（已有入口，逐文件操作成本高）或立即对接厂商查询API（尚缺真实接口版本、授权和样本，不能猜接口）。本次选异步保存链，使实际取得原件链接时有可验证的入库入口。下载不带API令牌、Cookie或额外授权头，仅使用链接自身签名。加密的萤石图片不进入此入口，须先完成官方解密链核实。

## 接口与数据

POST /api/v1/media-imports 接收targetKind(camera_event/flight_file)、targetId、requestKey、url、mime、evidence、readOnlyConfirmed、plaintextConfirmed；监控图片另需name。航次名称和期望SHA-256使用已有文件清单，不能由下载覆盖。监控若无厂家SHA-256，保存本次实下载校验值，明确不表示厂商一致性证明。

GET只返回权限内任务状态、目标、公开域名、关联assetId、实下载SHA-256/字节数和固定错误码，不返回URL、密文、URL摘要、凭据或私有存储路径。专家继续从明确分享的资料入口访问，不开放全场下载任务清单。原件本身使用已有逐次鉴权下载接口。

新增022迁移保存任务、发起人身份版本、来源契约快照、加密URL和状态。链接使用已有AES-256-GCM及独立AAD(media-import:<任务ID>)。请求键幂等；同键异内容拒绝。每个目标最多一项待执行任务，失败后可用新链接/新请求键提交。已关联原件不能静默覆盖。

## 下载与执行约束

全局MEDIA_REMOTE_READS_ENABLED默认0。MEDIA_IMPORT_ALLOWED_HOSTS是部署者核实后设置的精确域名白名单，不接受通配符。仅HTTPS 443，拒绝账户信息、IP字面量、片段和非标准域名。每次请求及每级跳转均重新检查域名和DNS；DNS全结果须为公网地址，实际HTTPS连接固定到这次检查的IP并验证原域名证书。最多3次跳转、整次20秒、最多20MiB、只取恒等编码内容；不转发Cookie、API凭据或Referer。

执行前后重查用户enabled/auth_version、对象read/record权限、来源verified/contract_ref/provider/对象、目标与任务租约。网络下载位于数据库事务之外。过期或中断的运行不静默重发，状态unknown，人工核对后再提交新任务。停止开关与域名范围在执行前和写入前重查。数据库只记录规范错误码，不能记录第三方错误正文或临时链接。

继续沿用当前原件库20MiB上限；大航次视频、正射大文件暂用已确认外部归档流程，不能因本入口通过就宣称完整支持。未提供单文件拍摄时间时保持空值，不用航次起止或告警时间代填。第二本机目录副本不等于独立灾备。

## 验证与完成条件

先验证公网/内网DNS、跳转越界、超限/压缩/状态码、完整超时与凭据不外带。再在agri_test随机schema验证监控告警通知不等待文件、任务幂等/冲突、SHA/格式失败、撤权/撤回来源/租约失效不入库、航次文件关联和备份校验、失败后换链接。正式网页测试检查状态、手机无溢出、未回显链接与专家隔离。跑全套单元/数据库测试、类型检查、构建、现有验收回归和隔离恢复；真实厂家及现场验收状态保持false。
