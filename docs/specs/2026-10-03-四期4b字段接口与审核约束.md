# 四期4B字段接口与审核约束

本页补充[4B详细设计](2026-10-03-四期4b农机服务与费用补贴详细设计.md)。所有数值和状态来源于明确的登记与证据，不自动对接政府、付款机构或机具控制。

## 农机接口

POST统一前缀`/api/v1/machinery/`；GET使用overview或export，并传objectId。

| section | 输入与处理 |
|---|---|
| contracts | objectId、provider、accountRef、fieldsRef、exportRef、migrationRef、exitRef、validUntil、sourceRef、supersedesId；资料不足可以登记，不可核实通过 |
| contract-reviews | id、action=approve/withdraw、evidence；五项答复、有效期、当前版本及独立审核人均检查 |
| bindings | objectId、machineDeviceId、terminalDeviceId、validFrom、validUntil、evidence；同对象已核设备，不是摄像通道；对机具和终端按固定顺序加锁核对时段重叠 |
| unbind | id、evidence；追加审计并记录撤回时间，不删除历史绑定 |
| orders | objectId、contractId、bindingId、title、operation、boundary、startsAt、endsAt、quantity、unit、sourceRef、supersedesId；工单初始为draft，窗口最多31天 |
| dispatch / cancel | id、evidence；dispatch权限确认，派单与取消分别留痕，取消不发送设备动作 |
| evidence | orderId、kind、passed、occurredAt、evidence、assetIds、track、supersedesId；轨迹、作业单、到户确认、抽查分别记录 |
| reviews | orderId、action=accept/withdraw、evidence；创建者和证据提交者不能审核自己的资料；引用当时四类证据ID |
| imports | objectId、contractId、sourceRef、rows；每行有externalId及evidence接口字段；每批1—100行/1MiB，逐行SAVEPOINT |

机具计费单位为mu、ha、hour、job。计划数量不自动视为实际完成量，实际数量和确认人写入作业单等原始证据。轨迹仅接受2—1000个`{at,lng,lat}`点，时间带时区、递增且在窗口内，经纬度为WGS84。原件须完整入库、同对象且当前可读。

每类证据更正追加新版本。四类证据齐全且人工标记已核后，另一个有review权限的人才可验收；依据更正、撤回或关联条件失效时，历史验收保留，当前可用性重新核查。费用核实时也核对关联服务单。

标准导入按契约、稳定来源、外部记录号跨账号防重；同号异内容拒绝。来源应标识同一终端或持续数据流，不应每次用新文件名冒充新来源。取得真实厂家字段和许可后仍需编写实际格式/HTTP适配。

## 费用与实付

POST前缀`/api/v1/business/`。经营明细只向有对象授权的owner、technician、admin开放；admin仍遵循既有动作范围，不能因管理员角色自动获得record/review。worker与maintainer不会因普通对象read授权而看到财务明细或综合经营报告。

| section | 输入与约束 |
|---|---|
| expenses | objectId、category、quantity、unit、unitPrice、amountCny、payer、payee、voucher、occurredAt、linkKind、linkId、evidence、supersedesId |
| reviews | id、action=approve/withdraw、evidence；独立审核，未知金额不批准；原始单据与历史版本不覆盖 |
| payments | expenseId、direction=pay/reverse、amountCny、voucher、occurredAt、evidence、reversesId；这里只登记实际凭据，不执行支付 |

金额仅CNY，最多两位小数；数量沿用六位定点。数量和单价齐全时，金额必须等于其乘积按分四舍五入。金额未知为null，不以0代替。付款为正金额，累积净实付不超过已核费用；原付款全额冲销保留原记录。已付款或被补贴占用的费用须先处理依赖，再更正。

付款方、收款方、凭证号经NFKC、空白与大小写归一后形成稳定身份，跨对象也不能重复建同一笔费用。原文字保留，错误主体或凭证需要人工核查；主体别名、伪造凭证或不同号码代表同一真实支出，系统不能自动识别。当前不实现一张原单拆成多对象分摊的财务系统。

`linkKind`为manual、input_purchase、protection_execution、machine_order、research_protocol、research_result。关联必须同对象且有访问权；科研协议或结果还检查相关小区授权。批次或作业已有材料数量不会因登记费用再次扣库存。

## 补贴三账

`claims`登记购置purchase、报废更新replacement、社会化服务service三类。字段包含objectId、policyRef、policyVersion、beneficiary、periodFrom、periodTo、expenseIds、amountCny、evidence。

申请引用1—50项当前已核费用，费用属于本对象及申请期间；申请额不超关联金额。费用在有效申请中被独占占用，按费用ID排序加锁并由数据库唯一约束防止跨类别、跨账号并发重复。拒绝或撤回会释放占用，原账及事件仍在。

`events`登记review、submit、award、received、refund、reject、withdraw、correct。内部复核不改变为已受理；受理、批准和到账各需自己的实际凭证。批准不超申请，累计到账不超批准；退回全额对应原到账，不能重复退回；有未退回到账时不能直接撤销申请。

政策适用性和实际资格由负责人员及主管部门核实。本系统只检查已登记费用、类别、状态、数值和关系，不作资格认证，也不自动抓取、填报或发送申报材料。

## 读取、导出与恢复

列表最近200条，费用累计汇总直接查全范围数据；汇总分别列登记金额、未知项与实付，不能当利润。导出按当前对象、角色和export权限校验；统一导出下载时再次检查财务角色，旧链接不能在降权后继续读取财务快照。

每表最多5000行、总8MiB；超限拒绝，不静默缺行。后台请求带稳定标识，跨账号保护取当前会话；部分导入保留原文和失败原因。14张4B新增表均要求非空恢复，核对合同、绑定、证据、付款上限与补贴占用。真实文件、单据、政策及人员签认归G17。

## 实际时间与追加更正

补贴外部事实另存occurredAt，未知留空；created_at只表示录入时间。内部复核与撤回记录本次服务器操作时间。correct动作以correctsId指向原外部事实，只追加时间与说明，金额、原凭证号及累计收付不变；页面同时显示原记录、当前更正时间和录入时间。043迁移保留旧记录实际时间为空，不拿旧录入时刻回填。
