# 二期2C三维与地形核验补充设计

本文件针对2ea8f04的实际软件补足详细操作和交付约束，日期2026-10-03。原2C设计记录需求W01—W10；本文件说明实施后的数据契约、权限与运维。文档补记不新增测绘结论。

## 一、端到端操作

1. 登记对象与资料来源；明确原坐标系、垂直基准、采集时间及转换依据。
2. 通过目录上传选择tileset及实际依赖文件，逐文件完成分块、长度与SHA核对。
3. 登记版本化场景及固定清单，排入terrain.validate。
4. 后台验证引用闭合、格式及资源范围，ready后可打开模型；失败保留原因。
5. 按资料录入独立检查点、控制点和排除区；缺资料可以只展示。
6. 专业人员填写用途、所需独立点数、水平/垂直容差及复核截止；审核与文件验证分别判断。
7. 录入已测设备高程、现场上下游连接；只有满足全部条件才能核算已测点剖面。
8. 导出与分享固定版本；变更、撤回、到期后当前用途失效，历史依据仍保留。

## 二、表及关联

| 表 | 主键与关键关联 | 不可变输入 |
|---|---|---|
| terrain_scenes | id；object/flight；supersedes_id唯一 | 场景版本、基准、来源、修补区、请求身份 |
| terrain_resources | scene_id+path | asset_id、checksum、byte_length、mime |
| terrain_surveys | id；scene_id；point_key+version | 实测和模型E/N/H、用途、独立性、基准 |
| terrain_reviews | id；scene_id；input_hash | 容差、统计、结论、用途、期限、审核人 |
| device_elevations | id；device/position_id；version | 高程、参考点、基准、测量来源 |
| hydraulic_links | id；scene_id；两端object | 方向、现场证据、版本、复核期限 |

迁移034追加在000—033之后；输入列使用preserve_measurement触发器保护。撤回字段可变，不允许静默改写已验证输入。版本和稳定requestKey有唯一约束，响应丢失后同内容重试返回原资料，异内容冲突。

## 三、状态与用途分离

| 包状态 | 可展示 | 可作为地形用途 |
|---|---|---|
| validating | 等待，不加载未验证文件 | 否 |
| failed | 显示失败原因，保留资料清单 | 否 |
| ready | 当前授权可展示 | 还须有效专业审核等条件 |
| withdrawn | 后续读取拒绝 | 否 |

用途不是scene上一个永久true字段。查询时重核当前审核输入hash、期限、未被新版本替代、地面覆盖、排除区和连通依据。仅供展示的审核可保留null容差；“接受地形用途”必须填写专业参数。

首次审核或分享后场景测量输入封存，补点须新版本。修订场景不会自动扩大旧分享。新版本使旧版本当前用途失效，历史仍可按原范围展示。

## 四、文件包契约与安全

| 限制 | 值 |
|---|---|
| 文件数、总量 | 1000个、2GiB |
| 单瓦片、单JSON | 64MiB、2MiB |
| 全部JSON、深度 | 16MiB、64层 |
| 首版分块 | 显式3D Tiles 1.0/1.1 |
| 模型与纹理 | GLB/glTF2、b3dm、bin、PNG/JPEG/WebP/ktx2 |
| 明确不支持 | 隐式分块、i3dm/pnts/cmpt及未知必需扩展 |

包引用只允许已登记的相对资源及受限内嵌资源。拒绝路径穿越、外部URL、循环、缺文件、校验不一致及跨对象媒体。根顶层LOD误差必须大于0，这是Cesium加载条件，不能作为测绘精度。叶级LOD可以为0。

上传复用一期媒体分块、续传和完整校验。worker在事务外读取文件，在提交前重核租约、创建者authVersion、对象及原件权限；旧身份作业不能继续发布结果。下载逐资源鉴权并在流读取中再检查撤权。

## 五、三种坐标分别保存

source_crs表示原资料；survey_crs表示核验用米制平面；呈现为EPSG:4978。垂直基准独立记录。经纬度或ECEF分量不能直接冒充平面米值。

每个检查点同时保存实测和模型E/N/H。程序计算dE、dN、dH，水平误差为sqrt(dE²+dN²)，水平RMSE为sqrt(mean(dE²+dN²))，垂直RMSE为sqrt(mean(dH²))；最大误差也保留。控制点不计独立检查精度，重复位置不凑点数，排除区内点不计有效独立点。

容差与点数由专业人员决定，软件没有默认农业精度。混合地表必须明确全部非地面/修补区域并确认声明；水面压平不能当作实际底高程。

## 六、高程和连通关系

设备高程绑定device_positions具体版本。survey_height使用声明的垂直基准；ellipsoid_height可空，仅用于三维位置显示。移位后不得继续把旧测量当当前位置；未核点位不能登记确认高程。

连通关系手工登记from/to对象、方向、现场证据及复核期限，两端均核权限。空间邻近不自动等于上下游通水。撤回关系保留原因，不删除历史。

剖面只接受明确已测点序列，输出平面距离、累计距离、实测高差和坡降。任何段穿过排除区、基准不一致、资料过期或权限缺失都拒绝。软件不从渲染网格自动采样，不把坡降转换成流量或发出控制指令。

## 七、页面与接口对应

/api/v1/terrain下的scenes、surveys、reviews、elevations、links、profile分别承担场景、测量、审核、高程、关系及核算。场景资源位于scenes/{id}/resources/{...path}；同路径不能绕过场景授权改用公开静态URL。

/terrain使用本地Cesium静态依赖，默认无ion、公共底图或外部遥测。手机先看二维说明，点击才加载三维。组件销毁时释放Viewer；WebGL不可用时显示错误及二维退路。专家授权包含固定包所有依赖，但不顺带开放其他媒体和后来新增场景。

## 八、运行、恢复与交付

安装依赖后prebuild/predev复制Cesium运行资源；public只存引擎静态文件，场景原件仍在私有存储。后台单独运行worker:terrain。容量上限为当前保护条件，不表示已压测全场模型。

ops/phase2-restore.ts在agri_test独立schema生成6张新表非空数据，备份删除恢复，比对125张应用表、模型文件SHA、关系及权限。生产PostGIS还包含spatial_ref_sys；两者计数口径不同。

本机更新前备份agri_dev及独立密钥，追加034、构建、重启当前应用与相关worker，核页面/API。回退优先上一构建；新表留存以免丢失记录，不能改写迁移历史。真实灾备链仍按G06，不拿同机目录副本代替异地恢复。

## 九、验收边界

W01—W10分项执行记录分别给出实现、测试、异常和交付物。实际浏览器加载的是合成模型，已验证目录上传、丢确认重试、WebGL、专业资料表单及撤权。真实测绘、厂家转换质量、地形适用性仍待G11；真实手机、全场数据规模和终端容量待G12。旧验收截图与新回归输出分目录保留，不覆盖一期原始证据。
