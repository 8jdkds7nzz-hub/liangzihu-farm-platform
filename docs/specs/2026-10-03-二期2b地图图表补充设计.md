# 二期2B地图图表补充设计

对已实现2B进行2026-10-03文档补记，基线2ea8f04。原详细设计、源码和历史验收保留。本文件展开操作、数据口径和异常语义，未将文档整理当作新增现场实测。

## 一、用户任务与入口

| 任务 | 入口 | 完成标志 |
|---|---|---|
| 找到地块或塘口 | /map名称搜索→结果按钮 | 对象聚焦，仍可进入详情 |
| 看资料覆盖 | 对象/设备/航次覆盖/注记等图层开关 | 当前图层数量、缺口可见 |
| 核对异常测值 | /points/{id}历史曲线→点详情→原值表 | 时间、数值、单位、质量能对上 |
| 比较指标窗口 | /analysis选择指标定义 | 当前载入同窗口最新版本可辨 |
| 手机巡查 | 二维视图及列表 | 不依赖加载三维引擎 |

搜索和图层开关只影响当前授权数据的显示，不执行全场隐式查询。对象没有几何时仍能从列表进入详情，并提示缺资料，不用随机坐标填充地图。

## 二、二维图层的数据来源

GET /api/v1/map沿用一期对象边界、设备点位、航次覆盖、配准栅格和注记服务。每个资料保留对象、来源及版本；专家读取固定分享事项。底图坐标EPSG:4326，已有正射必须通过配准核对才能进入对应展示。

二维绘制不请求公共底图，也不利用屏幕距离推算实地距离。边界可信程度、资料采集日期、覆盖缺口继续随业务数据提供；“可画出”不等于已经测绘核准。

## 三、交互规则

1. 输入对象名筛选结果；选择结果后聚焦该对象，相关入口仍按对象原权限跳转。
2. 图层开关保持同一视图位置，数量反映当前加载集合。
3. 按钮执行放大、缩小、复位；方向键平移，0键复位。
4. 鼠标或触摸拖动进行平移；拖动动作不误触发对象详情链接。
5. 对象选择、键盘操作和图层切换不修改真实几何。
6. 页面缩放、手机尺寸变化后保留可访问按钮；二维入口独立于三维加载。

视图变换属于客户端临时状态。没有服务器保存“最后地图位置”业务记录，不把相机位置当作实物位置。

## 四、测点图表输入

chartSeries(input,maxGapMs)接受ChartPoint：id、time（毫秒）、value（number或null）、valid、可选label。输入先剔除非法时间并按时间升序处理。

| 情形 | 点呈现 | 连线 |
|---|---|---|
| 有效0 | 保留0点及详情 | 满足间隔时可连接 |
| null/非有限数 | 不创造点 | 断开 |
| 有数值但质量无效/可疑 | 可作为质量点显示 | 不进入有效连续线 |
| 时间差超过maxGapMs | 两端原点保留 | 断开 |
| 未确认连续间隔maxGapMs=null | 原点保留 | 离散点，不推定持续 |
| 所有点同值 | 原值不变 | 坐标轴自动加边距 |
| 无有效数值 | 空状态/原表 | 不出现默认正常曲线 |

domain只用于画布坐标；无点时的轴占位范围不是业务测量值。图表禁止把数组下标当时间、用0补缺测或跨冲突连接正常曲线。页面仅展示当前已加载时段，不宣称覆盖全季。

## 五、指标趋势契约

MetricTrend接受definitions及items。items包含definition_id、value、unit、status、window_start/end、version、limitations。

按选中定义筛选，再以window_start/window_end为键选最大version；选择发生在当前已加载集合内。出现多个单位时提示核对并停止绘制。定义已撤回时保留历史表但不绘为当前可用趋势。仅status=usable且value非空的结果进入有效点。

窗口结束时刻作为横轴，标签保留完整起止时段和版本。不同窗口默认不连线。指标原始来源、覆盖率及限制仍由原服务计算并在列表显示；图表本身不重新解释农业因果。

## 六、可访问与失败状态

TimeSeries提供可聚焦的点详情；键盘可以读到真实0值。表格保留，颜色不是质量信息的唯一表达。加载失败通过共用请求状态显示错误与重试，不能把“没有读到数据”画成平稳正常。

未知单位显示未登记，缺边界、缺位置、未配准分别说明。服务端401要求登录，403说明范围失效；地图切换不能扩大授权。复杂三维失败时保留二维路径。
