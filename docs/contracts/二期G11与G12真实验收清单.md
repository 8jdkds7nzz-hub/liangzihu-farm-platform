# 二期G11与G12真实验收清单

用户当前暂不具备现场试点条件，本轮继续完成软件研发。下列验收保持待完成，与一期G01—G10并行登记。

| 编号 | 待取得的真实资料 | 验收内容 |
|---|---|---|
| G11-01 | 实际机场/飞行器/固件/司空或智图版本、建模许可与交付样本 | 实际格式、转换、完整依赖、下载与费用，不从拟采购型号推定 |
| G11-02 | 坐标系、垂直基准、ECEF呈现转换方法及版本、米制测量平面对应依据 | 确认原始、核验、呈现三种基准及点位对应；未知不填0 |
| G11-03 | 采集日期、裸地/冠层/水面状况、控制点和独立检查记录 | 专业人员确定点数及平面/高程允许误差，复算每点差值、最大误差与RMSE |
| G11-04 | 水面压平、修补、冠层和未测区域边界及依据 | 明确展示修补与可用于地形的范围，排除区不用于精度或剖面 |
| G11-05 | 设备安装基准、测量高程与水位计参考、现场上下游连通记录 | 对应明确点位版本、两端对象与方向；地图邻近不代替连通 |
| G11-06 | 年度复核和土建变更负责人/流程 | 到期降为展示、变化撤回、新版本独立核验；不延续旧适用性 |
| G12-01 | 真实文件数、单瓦片/总量、纹理尺寸、并发与网络条件 | 在现保护上限内实测，超限先调整加工分块与经验证配置；不以小合成模型外推全场容量 |
| G12-02 | 实际电脑、iOS/Android/企业微信及备用浏览器型号版本 | 首屏/流畅度/内存、弱网/中断/空间不足与退出恢复；手机二维默认可用 |
| G12-03 | 私有存储、备份与发布环境、负责人和实际数据规模 | 模型及权限恢复、文件链、原件缺失/校验错、旧客户端兼容和回退；真实RPO/RTO另验 |

代码已支持界面、私有文件链、资料核验及实测点几何核算。当前没有真实农场地形验收、2000亩高精度模型容量证明或实际设备控制；G11/G12不会因软件测试通过自动变为通过。
