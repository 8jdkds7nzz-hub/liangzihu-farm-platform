## G16 能源采购、厂家适配与现场验证

baseline中的新增太阳能储能尚未采购，不能由闸门原配太阳能推定已经建成新增储能系统。现有4A提供设备计量档案、人工/文件观测、版本、差分和环境参考；**没有实现新增能源厂家自动采集适配器**。

| 需取得的真实资料 | 后续开发与验证 |
|---|---|
| 采购清单、机型、固件、实装编号、独立计量范围 | 对应现有设备对象，区分发电、负载、储能和闸门原配供电 |
| 接口许可、通信方式、寄存器/字段、单位、倍率与正负号 | 按具体版本编写只读适配和转换，保留原值；不猜测正负净功率语义 |
| 累计表值复位、溢出、采样/上传间隔和历史补传 | 用厂家脱敏报文验证差分、断段、重复与更正 |
| SOC/SOH、充放电状态、保护与告警语义 | 分开显示测值、厂家状态和人工判断，不据此自动控制负载 |
| 电表与溶解氧等测点对应、专业使用条件 | 现场核查时钟、单位、范围和缺口；节能效果需要独立实测 |

代码能够录入和计算，不等于采购、真实采集或节能验收已经完成。

## G17 循环物料、农机、费用与补贴

循环物料需要实际来源批、秤单、设备校准、含水率测法、处理批及筛分返料、检测适用范围和去向。以真实批次做一次接收—处理—检测—放行—交接对账，差异不能只写笼统“损耗”。软件没有替代质量/环保专业判断。

农机接入先取得账户、字段、导出/接口、历史迁移、退出五项书面答复。当前实现标准JSON及跨账号防重，**没有编写未知省平台或厂家终端的实际HTTP/专有文件适配器**。取得权益、真实文件和字段后，再完成实际格式转换与联调，不能用合成JSON当厂家兼容证明。

需要实装机具和终端对应、时间基准、坐标系、轨迹精度、作业窗口、作业单、到户确认和抽查方法。计划量、轨迹和实际完成量分别核实；不只凭轨迹付款，不代替省平台。

费用与补贴需要真实付款/收款主体、原单身份、计费单位、金额、实际发生日期、付款/受理/批准/到账凭证，以及具体政策版本、适用地区和官方口径。当前仅做登记与内部检查，**不执行真实支付和政府申报**。

同一主体凭证的归一匹配、有效费用独占、金额上限已测试；主体别名、虚假单据、另开号码但代表同一支出的情况仍须人工核对。内部审核不是补贴资格认证。

## G18 科研与管理指标

由研究负责人确认问题、基线、真实小区、处理/对照、独立重复、观测方法、计划样本量、第三方检测、停止条件和审核责任。当前软件没有自动给出试验设计的统计学充分性结论。

以真实报告验证协议修订、缺测、更正、旧结果回读、经费关联与专家权限；需要真实且独立的证据才能认定成果。“可核实／官方口径／自报”是登记性质，不是系统授予认证。

管理指标需要核对各对象实际登记覆盖率、时间口径、人员操作习惯及目标终端容量。工程测试证明240条费用没有被界面200条上限截断，但不能证明真实全农场规模已经通过容量验收。
