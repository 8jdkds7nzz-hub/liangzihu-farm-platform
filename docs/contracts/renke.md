# 仁科接入契约状态

G02未交付适用型号/固件、只读接口授权、字段文档及真实脱敏报文。当前没有已启用的厂家HTTP适配器，没有生成猜测的仁科URL、状态码或字段名。

已实现契约驱动的字段翻译、统一测值、原始字节与校验值保存、并发去重、冲突留存、事务游标及文件回放。`RenkeContract`逐项声明列表/设备/记录编号/三类时间/数值/状态字段、时间格式、原始与标准单位、换算和平台测点。文件回放使用`persistBatch`的`resolveMappings`模式，在测点行锁内按每条采样时间选择已核实的历史绑定；混合跨换塘批次不会都归到当前对象。契约兼容字段bindingId不代替平台台账。只有带版本和依据且标记核实的契约可用于真实回放；合成模式只能写入agri_test。

测试使用明确名为“合成列表、合成设备、合成状态”的字段，不表示仁科真实协议。正常零值保留；离线零值保留rawValue但不进入有效value；无原始采样时间不拿收到时间替代。未识别状态或映射拒绝/隔离，游标仅在该批持久化后推进。

G02补齐后还需实现并实测：服务端令牌保存/刷新、分页与时间窗、限流及重试、HTTP失败不跳过游标、断线补数、状态健康、采样/上报时间和单位含义，完成一次只读实时链路。本轮回放不代表实际拉取或接收设备数据。

当前合成翻译器以“外部设备ID＋指标”作为唯一测点映射键。正常/离线状态代码重叠、映射缺失或重复会拒绝，不取第一项。真实厂商若以独立通道或每指标状态描述多个同类探头，必须取得G02后扩展实际契约并回放验证，不能把本轮行级状态样例直接套用到多通道设备。成功回放随原报文保存白名单契约快照、版本、依据与SHA-256；共享快照不作为无鉴权公开文件提供。
