# Q01统一检查与验收产物隔离实施计划

> 按用户已批准的Q01范围自主实施，不派遣额外代理。详细约束见[设计](../specs/2026-10-03-Q01统一检查与验收产物隔离设计.md)。

**目标：** 给现有检查增加可复现入口、独立产物和失败记录，保留历史验收原件。

**结构：** `tests/support/artifacts.ts`负责安全产物路径；`tools/verification.ts`负责步骤执行和清单；`tools/check-project.ts`负责固定套件、前置核查及CLI；原测试/评测/恢复只替换产物位置。

**约束：** 不新增依赖，不改业务源码及迁移；只用测试数据库，外部服务默认禁用；完整构建在独立工作树执行。

## Q01-1 产物隔离

- 新增`tests/support/artifacts.ts`、`tests/unit/verification-artifacts.test.ts`。
- 输入：相对产物路径及可选本轮目录；输出：验证过的绝对路径，所需父目录已建立。
- [x] 先写越界、历史目录拒绝、符号链接拒绝、两轮目录不同的失败测试。
- [x] 实现固定`.local/验证记录/`根目录、私有权限及子进程共享目录。
- [x] 将全部测试/评测/恢复中的固定输出路径迁移到辅助函数；真正的测试输入、临时夹具及模型缓存保持原用途。
- [x] 扫描剩余固定写入并核对删除已无用的导入。

运行：`node --import tsx --test tests/unit/verification-artifacts.test.ts`。越界和符号链接不能在目标外创建或写文件；正常路径可写，两个运行目录不相同。

## Q01-2 步骤执行与清单

- 新增`tools/verification.ts`、`tests/unit/verification-runner.test.ts`。
- 输入：固定步骤列表、前置判定、子进程环境；输出：带状态/耗时/退出码/统计/文件哈希的`运行记录.json`。
- [x] 用临时Node测试构造通过、断言失败、跳过和缺前置，先验证执行器应返回的结果。
- [x] 实现逐项执行、私有日志、依赖阻塞、超时/中断、测试统计和最终非零判定。
- [x] 加入历史目录前后哈希核对；发现变化只报告，不自动还原。
- [x] 验证缺前置不会执行该步骤，独立步骤仍执行；重复运行不复用旧结果。

运行：`node --import tsx --test tests/unit/verification-runner.test.ts`。失败/跳过/阻塞不显示整轮通过，正常对照通过；执行器自己的受控反例是测试通过的依据，不算平台故障。
