# 一期1a接入与恢复补齐计划

依据用户连续完成一期的授权及原A01/A04/A07/A10缺口执行，不改变已确认设备数量和手动灌排边界。

1. 企业微信服务端令牌、身份兑换、单成员推送和管理员映射。验证：替身协议、一次性OAuth状态、成员拒绝、最小对象授权；实际G03仍待联调。
2. 专家短信与语音采用阿里云中国站官方SDK作为可替换的首版实现。仅登记专家手机号可登录，不创建账号或授予事项；5分钟验证码、浏览器绑定、一次性核销、发送/猜码限流。电话仅已有严重事件升级，用CallId查详情，接通不等于接管。验证：SDK替身与数据库并发/过期/撤权；默认不发送。
3. 仁科按已核契约做HTTPS只读分页拉取。接口地址、游标、字段、状态和凭据引用明确声明；每页成功持久化后推进游标，来源/主体变化拒绝。验证：分页、失败、并发游标及撤权；G02真实协议不从型号猜。
4. 补WAL归档、基础备份与私有NAS核查和恢复操作工具，保留独立密钥备份。验证：本机隔离备份/恢复；真实存储独立性、RPO15分钟和RTO2小时需现场演练。
5. 全套一期测试、非空新增表及大原件恢复、设计与验收逐项对照、保留已有账号密码登录设置，提交私有仓库。

验收口径：软件闭环、合成工程测试、真实厂商联调、专业质量和生产恢复分别记录。开关不会因为编写适配器而自动启用；不拨打或通知真实人员，不开放设备控制。
