# 监控与航次原件接入实施计划

用户已授权自主完成1b/1c；本轮主代理按步骤执行并自审，不另派子代理或重复询问。

**目标：** 把已获授权的监控/航次下载链接转为校验后的私有原件与可靠关联。
**结构：** 追加022任务表，下载器独立处理HTTPS和公网边界，业务服务处理幂等、权限和关联；现有media worker处理下载与备份。
**技术：** Node HTTPS/DNS、PostgreSQL、既有AES-GCM/私有存储、Next 16.3.8；不新增依赖。

## 全局约束

- 外网读取默认关闭，不连接真实设备、不发送真实告警。
- 只处理20MiB以内已解密文件；航次SHA-256不可覆盖。
- 临时URL加密，错误/公开列表不带密文或链接。
- 测试仅agri_test自身随机schema；迁移只追加022。
