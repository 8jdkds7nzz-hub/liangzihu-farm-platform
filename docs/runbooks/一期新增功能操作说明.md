# 一期新增功能操作说明

## 技术员与负责人

- 地图页切换对象、设备、航次覆盖、正射和疑点图层，拖动平移、滑条缩放、复位。登记点位/覆盖时填写实测坐标及依据；只有已核北向WGS84正射才能生成预览，其他投影先在原加工软件输出。不把图片点击位置当经纬度。
- 选择前后两时期的具体成果，查看日期、采集条件、配准来源与缺口；不同对象只分别查看。影像页选原件点击疑点，登记限制和来源。给专家分享具体版本及附件，另确认基础对象查看资格和期限。
- 影像页“大原件分块上传”填写对象、来源和文件，来源有SHA则填写。失败后保留会话ID，重新选择同一原文件和会话继续，已确认块不重复。后台整体SHA完成后才算完整；点“刷新核验与备份状态”确认原件及副本，再关联航次。
- 任务页展开“重新指派并交班”，核对新的执行人、原因和未完成内容，确认后旧领取解除。新执行人重新领取，实际观测/判断/动作分别反馈；已反馈/复核/取消的任务不退回待领。
- 分析页登记公式来源、单位、完整率、时间窗和物种阶段；审核后计算。简报页登记日/周/月计划，后台每项计算独立处理；指标失败时仍有带缺口的程序报告。补传产生新的计算版本，不倒放实时电话。
- 简报逐项采纳/修改/驳回，再预览指定接收人的版本，确认事项和期限。接收人登录“已分享简报”入口查看；撤回后下一次请求拒绝。转任务只建草稿；在任务页另确认派发。未知模型账单在问答页核回执，不补造答案或重发。
- 图片完整保存后自动排唯一图片复核。失败保留未完成，可注明原复核和原因重试；它不改原告警或认领。抽查样本由另一位有资格人员独立标注，人/车可同时存在，未知不填阴性。场景分母为0显示未验证。

## 管理员

- 配置页“本人身份与登录方式登记”用于已开通账号，先核实企业成员或专家本人手机号及用途；不增加对象/事项权限。真实登录/通知开关、模板、可信域名和号码仍由联调清单确认。
- “人工核验后的账号恢复”登记理由及核验记录，恢复码仅显示一次，30分钟有效，经已核私下渠道交本人，在`/recovery`由本人设新密码。完成后清除本页显示。不要把身份证原件、恢复码或厂商密钥填进依据。
- 当前本机仍按用户选择使用账号密码登录；MFA开关重新启用时，需要按照原身份策略二次验证。操作卡中的首次TOTP步骤只适用于该策略启用时。

## 运维

新增迁移025—033只能向前应用，已应用000—024不修改。真实读取/发送默认关闭，资料和开关不足时返回待核/未启用。只读摄像头请求经平台短期私有代理播放，不把源URL或凭据复制给用户；没有云台预置位、闸门或飞行控制。

媒体/知识/智能/图片/天气/摄像头/司空进程独立。更新前备份数据库、媒体和独立密钥；更新后核迁移、构建、当前授权、积压及待核调用。回退先停新增入口和工作进程，保留新增表、原件、未知回执与账本，不做DROP回迁。生产WAL/NAS操作见[持续备份与恢复](一期持续备份与恢复.md)；本机副本不替代生产灾备验收。
