功能全景采用分类布局，不用箭头暗示六个板块之间存在业务先后。架构图保留同一个 Next.js 工程的边界，并明确后台任务通过数据库队列领取工作。流程图横向阅读，紫色节点同时写明人工核查、确认或审阅，不单靠颜色表达含义。

图示使用 SVG，文字和连线可无损放大。README 保留文字说明和可跳转目录，点击图片可查看矢量原图。图中“待真实联调”和“尚未实现”不会因视觉优化变为已交付。

## 采用的开源技能与引擎

- [Mermaid Diagram skill](https://github.com/trikitrok/mod-mermaid-diagram-skill/blob/main/skills/mermaid-diagram/SKILL.md)：采用分图说明、按语义分层、减少交叉线，以及先渲染再检查的方法。复杂信息分别放入功能、架构和流程图。
- [Pretty Mermaid skill](https://github.com/imxv/Pretty-mermaid-skills/blob/main/SKILL.md)：采用可编辑 Mermaid 源文件、明确主题、SVG 输出和中文布局检查。四条流程实际使用其推荐的 `beautiful-mermaid` API 渲染。
- [beautiful-mermaid 1.1.3](https://github.com/lukilabs/beautiful-mermaid)：以固定版本渲染流程节点与连线。功能和架构采用本项目 SVG 排版，流程图把四个独立渲染结果排列为四行，并隔离各自的样式与标记。

以上是本次读取并采用的开源工作方法。没有把第三方 skill 或渲染器复制到应用中，也没有增加应用运行依赖。配色、中文内容、分组与图示布局由本项目编写。

## 重新生成

在项目根目录执行。依赖安装到独立临时工具目录，不改变应用的 `package.json` 和锁文件：

```sh
npm install --prefix /tmp/智慧农业绘图工具 --ignore-scripts --no-audit --no-fund beautiful-mermaid@1.1.3
node docs/架构图/绘制图示.mjs /tmp/智慧农业绘图工具/node_modules/beautiful-mermaid/dist/index.js
```

绘图脚本以 `src/components/platform/app-shell.tsx` 的菜单为功能图输入；业务流程内容和架构坐标在脚本中维护。脚本生成三份 SVG 和四份 `.mmd`，改流程时应修改脚本中的源内容，再生成对应文件。

每次更新须核对导航数量、图中中文名称、箭头语义、未实现边界和 SVG 文件有效性，并在浏览器按 README 实际显示宽度检查文字、连线、底部说明与截图。仅修改这些文档图示时，验收对象是图示，不重复计算历史软件测试成绩。
