# 值班人员操作卡

适用：1a在线文本流程。当前厂家与真实通知渠道尚未验收，平台不能代替现有现场值守。

1. 登录后打开“值班安排”，核对对象、时段和升级联系人。安排缺失或不符时联系管理员核实，不凭默认名单接班。
2. 从“对象台账”进入相关测点，看采样时间、数据质量和新鲜度。通信成功不等于测值新鲜；未知、待核或缺测时转现场检查。
3. 在“告警与核查”打开事件，明确点“认领现场核查”。收到消息、电话接通或维护人员认领排障，都不代替你的现场认领。
4. 到场后填写观察结果、仪器/复测依据和现场情况，点击保存。看到错误或断网提示时不能视为已保存；恢复网络后重试，提交内容保留在当前表单。1a不保证关闭页面后保存离线草稿。
5. 维护人员另行认领排障并记录措施。测值恢复只表示“恢复待关闭”；关闭须引用核查和处置记录。仍未恢复时，只有经专业审核为误报才可关闭。
6. 交班时核对未关闭事件，写清接班沟通和未处理事项，再结束自己的认领。接班人员必须明确重新认领；不要用退出登录代替交接。

发现平台、监测或告警不可用时，按现场已有方式联系管理员与当班责任人，直接核查关键点位。平台恢复后补录实际发生时间和依据，不把恢复时的旧数据当作刚采到的新值。

夜间严重事件首次实际发起通知后3分钟仍未接管，按当班→技术员→负责人升级。该规则的真实渠道仍待G03/G04联调；当前开发版不会实际拨号。
