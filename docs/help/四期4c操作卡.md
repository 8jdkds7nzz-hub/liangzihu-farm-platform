# 四期4C操作卡：科研试验与综合指标

入口：`/research`、`/management`。[设计与交付](../acceptance/4c/实施进度与交付物.md)。软件保存证据与计算记录，不自动证明因果、增产或盈利。

## 建立试验

1. 先在配置管理登记真实小区，明确边界状态并授权。未知边界可以登记，但不能据此认定面积精度。
2. 选择对照与处理小区，同一对象不能同时属于两组。
3. 填研究问题、基线、各指标的代号、名称、单位、方法和每小区计划观测条数。
4. 写明实际试验窗口、第三方检测计划、停止/调整条件及依据。资料缺口应写明，不虚构机构承诺。
5. 请独立人员审核协议。修订时引用原协议版本，新版本再次审核。

## 记录观察与报告

选择当前协议、指标和小区，按统一方法填写稳定观察号、数值和实际时间。未知值留空并说明原因；0只有明确测得时填写。

第三方报告需出具机构、报告编号/版本及已完整入库的原件。附件须属于试验对象或当前小区，并有读取权限。原值错误时引用当前观察版本追加更正，不覆盖旧记录。

## 生成结果和登记经费

1. 生成固定结果包，填写成果说明、限制及来源，选择“可核实／官方口径／自报”。
2. 核对每个小区的观测条数、计划缺口、均值和范围。记录条数不是独立试验重复数。
3. 独立审阅者登记意见；原观察或协议变化后，旧结果仍显示旧输入，并提示依据已更正或撤回。
4. 经费从“费用与补贴”登记，关联协议或结果ID；不另建第二套重复费用。费用与实付分开查看。
5. 专家需要资料时，只分享固定协议或结果，设置期限。照片和检测原件需要另外的媒体授权。撤回后旧链接无法继续读取。

整包导出需试验对象和所有涉及小区的export权限；没有小区导出权限时，即使可以阅读也不能打包导出。

## 综合指标

有财务角色和对象授权的人员选择对象、开始/结束时间与用途，点击生成。后台进程`worker:management`完成后刷新查看；不是点击后直接改写旧报告。

七组记录覆盖设备、作业、质量、调度、经营、服务和风险。阅读时先看范围、生成时间、定义版本和缺口：

- 有效观测占比的分母是收到的规范观测，不是应采样数，不等于在线率。
- 无数据或无分母显示未知；0条告警不能证明现场无风险。
- 已知费用、金额未知项、净实付分别显示，没有完整收入账目就不计算利润。
- Now类字段描述生成时点；其他字段使用开始包含、结束不包含的窗口。
- 修改了基础记录后，需要生成新报告；旧报告保留原快照。

每人最多5份待处理报告。超过输入条数、8MiB或计算预算时缩小范围；不把前台最近200条误认为全量。真实试验和指标覆盖签认见[G18](../contracts/四期真实资料与接入适配交接.md)。
