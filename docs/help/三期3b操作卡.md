# 三期3B操作卡

入口：/traceability。选对对象和批次，先准备原始报告及凭证。

1. 登记样品，明确原料/采收或加工成品阶段；登记方法、结果、报告依据、检测时间及适用期限。
2. 错误报告以更正关系追加，不能改掉原报告。合格证、认证和品牌授权分别登记主体、产品、期限及核实依据。
3. 由其他有review权限人员，按当前批次版本选择依据，明确决定放行或保持待检/受限。已存在失败/无法判断结果或未结问题时先处理。
4. 选择正向/反向追查，查看版本、边界和缺口。无关系不等于全链完整；旧快照也要当前授权才能打开。
5. 质量问题按实际通知、追回、处置逐笔记录。通知入口只登记凭证，不会替你发送消息。未完成量保持未结案；结案不会自动重新放行。
6. 客户页先写公开草稿，再由另一名有review+share权限的人审核。产品名称与批次一致，批次标签使用独立公开标签；只写省市县，不写内部ID、地址、电话或私有链接。
7. 发布后用匿名浏览器检查内容；出现问题时撤回。新请求立即停止访问，已保存的截图无法收回。

公开页还受当前质量、凭证和有效期限制。不能把人工写的摘要当成软件自动认证。正式查询导出额外需要export权限。

真实检测、行政资质、品牌授权、签收与处置证据按G13核实。本期没有自动联网验证证书真伪，也没有自动对外召回通知。
