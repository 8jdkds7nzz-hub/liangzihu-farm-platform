# 现场人员农事与离线操作卡

1. 首次联网登录，打开“农事与照片→现场记录”，设置本机草稿PIN。记住PIN；丢失后无法解密本机内容。
2. 选择对象与已确认的生产批次；未关联批次保留空白，不猜测。填写实际发生时间、观测、判断和动作，未知用量留空。位置只在本人同意后取得。
3. 选择照片并“保存到本机”。等待确认“已存本机”；原图和压缩预览分别保留。关闭重开用PIN解锁，继续编辑尚未提交的本机草稿。
4. 联网后同步。只有表单和全部附件确认才显示“已同步服务器”。失败、版本冲突或撤权时保留原草稿，按原因处理；不要为同次事件随意新建提交ID。
5. 今日任务先明确领取，现场反馈分别写观测、判断和实际动作；领取不等于到场。交班写说明并解除自己的领取。
6. 闸门/灌排只做人工申请、确认、执行与结果登记，平台不发动作。告警仍在原入口认领和处置。

当前只验证本机Chromium；企业微信、手机型号和关闭后台行为须逐个实测后声明支持。
