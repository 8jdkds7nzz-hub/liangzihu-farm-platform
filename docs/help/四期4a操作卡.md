# 四期4A操作卡：能源与循环物料

适用入口：`/energy`、`/circular`。本机软件已验证；厂家自动采集未完成，不能据此替代现场仪表和原平台。[设计与交付](../acceptance/4a/实施进度与交付物.md)

## 开始前

请管理员先登记实际对象、物理设备、测点或仓位，并分配read、record、configure、review、export等所需权限。不要把报价设备当已安装设备，也不要把闸门原配太阳能与新增储能混为同一套。

能源资料由配置人员登记，独立核实由另一个有review权限的人完成。循环物料先在“库存与批次”登记kg批次和仓位，明确湿基、干基或原样。

## 记录能源

1. 在“能源记录”选对象，登记物理设备、用途、容量、观测间隔及计量依据。容量未知留空。
2. 如需并列溶解氧等参考，选择已核绑定的环境测点；不确定对应关系时留空。
3. 请另一人核实能源档案；物理设备未核实不能通过。修订档案时引用旧版本，重新审核。
4. 记录实际发生时间、指标、标准单位值、质量、运行状态、原始值与换算依据。未知值留空并选缺测，可疑值不要标有效。
5. 累积电量表复位时勾选复位。更正同一时点读数时引用当前版本，原值继续保留。
6. 选择累计kWh指标与时间窗计算差分。只把明确完整区间的结果当该窗口记录；有缺口时查看已知片段和原因。

当前数值接口采用非负标准幅值；有正负含义的厂家净功率等信号须先核实方向和口径，不直接取绝对值导入。功率、电量和电池百分比不能互换，也不会触发设备动作。

## 接收和处理物料

1. 在“循环物料”把已有库存批次登记为循环物料，补来源批与用途依据。
2. 接收时填毛重、皮重、净重、鲜干基、含水率、凭证号和实际时间。净重必须等于毛减皮，未知含水率留空。
3. 保存称量会同步入库，不要再到库存页面重复入库。同一对象的相同称量凭证不能重复登记。
4. 检测与放行到“质量与溯源”办理；未放行的输入不能加工，输出仍为待检。
5. 处理、筛分、返料填写输入输出批次、仓位及数量。返料使用新的输出批次，不能把原来源批回写成新料。
6. 数量差额或不同鲜干基需要原因及review权限。辅助干重不会改写库存口径。
7. 包装、发货和实际签收继续在库存办理；问题批次在质量模块追查和处置。

## 异常与核查

| 提示 | 处理 |
|---|---|
| 暂不能判断完整电量 | 查起止观测、复位、质量与间隔，不填平缺测 |
| 相同凭证已登记 | 先查原记录与库存，不换一个凭证号重复记同一事实 |
| 质量依据失效 | 回质量模块核查检测、凭证和问题记录，再决定后续动作 |
| 账号已改变 | 保留草稿，回原账号核对或重新整理该账号自己的记录 |

页面每类最多200条；“导出当前对象与关系”另查export权限，超过上限会明确拒绝。正式生产前须完成[G16/G17交接](../contracts/四期真实资料与接入适配交接.md)。
