# 三维与测绘资料操作卡

适用：有对象资料维护、审核或分享资格的人员。手机默认使用二维，三维按需打开。

1. **准备资料。** 从原加工工具导出本期支持的显式3D Tiles目录，保留根tileset及实际引用的GLB/glTF/b3dm、纹理和二进制文件。记录原坐标系、核验用米制平面、垂直基准、转到WGS84 ECEF的方法/版本、采集时间与地面覆盖。坐标/高程未知须写明，不能填0或猜转换。
2. **登记成果。** 打开“三维与地形”，选择对象、场景名称和目录内根文件，勾选实际依赖文件。系统逐文件分块保存并核SHA，随后后台核验包内引用。中断后重新选择原文件可继续；账号安全状态变化使旧上传会话失效时，明确选择新会话。核验失败查看原因，修改后追加版本。
3. **查看模型。** 包通过后点“打开三维视图”。鼠标拖动旋转/平移、滚轮缩放；不能启用WebGL时返回二维。无专业验收的模型标“仅供展示”。边界线依参考椭球示意，不能当作地面高程；橙色区域为排除区。设备缺已核椭球高时不画三维点位。
4. **登记测量。** 将控制点、独立检查点分别登记，实测与模型的E/N/H均为同一测量平面/垂直基准的米值，另登记对应经纬度。保留测量时间和独立来源。位置重复不能凑独立点数；更正引用原版本。首次审核或分享后资料封存，新增须新场景版本。
5. **专业核验。** 专业人员填写本次用途、允许误差、所需独立点数与一年内复核日期，确认基准、裸地和排除区。系统计算误差和RMSE；资料不齐、数量/误差不达标时不通过。仅供展示时容差可以留空，不填虚构精度。
6. **连通与剖面。** 现场核对两个对象的上下游关系、方向、证据和复核时间。按方向依次选择已测点，程序仅核算点间平面距离、高差和坡降；未核/过期/修订/穿排除区时拒绝。这不是模型表面自动测高、水位推断、流量或控制建议。
7. **设备高程。** 选择明确点位版本，登记安装参考、实测高程、垂直基准、转换依据与可空的椭球高。设备移位后重新登记，新点不会沿用旧点高程。
8. **分享与撤回。** 选择场景、具体点位、高程或连通资料及接收专家和期限。模型授权包含该版固定文件包及已登记测量资料；其他图层分别授权。专家还需基础对象查看资格，连通需要两端资格。撤回后后续访问拒绝，不承诺收回已下载文件或截图。

土建、基准变化或资料错误时，及时撤回场景/连接并追加新版本。真实精度、实际模型格式和规模、移动终端性能必须另验。工程样本和软件检查不能代签现场测绘或灌排验收。
