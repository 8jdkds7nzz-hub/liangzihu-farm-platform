# 三期3A操作卡

入口：/inventory。操作前确认当前账号与对象，批次和仓位按名称选择；当前列表每类最多200条。

1. 建仓位、建批次。录入品名、类型、单位、原样/干/湿口径及可确认的外部批号；未知信息不编造。
2. 采购凭证单独记录。实际到货后做入库；采购记录本身不增加库存。
3. 新到货为待检，到质量页由其他审核人员核查放行。旧放行批次不追加新到货；退入也用待检批次。
4. 领用扣减仓位库存，实际施用另记并引用领用单。不要把领出数量全部自动记为已经施用。
5. 加工先建待检输出批次，再输入各批及仓位数量。相同单位口径才比合计；损耗、增量或不同口径必须说明，由有审核权限人员处理。
6. 装箱/拆箱是包装关系；发货、实际签收分别记，少收和分次收货继续可见。
7. 录错时核对原单和下游依赖，用冲销或追加说明，不删旧分录或直接改余额。

保存失败时当前表单保留输入；丢确认在同一表单重试。换账号后旧表单会拦截提交，先保留原草稿，重新登录正确账号核对。刷新/新开表单是新提交，重新录入前查看现有单据。

看“审核状态”还要看“当前可用性”：报告过期或有未结问题时不能因旧available状态继续使用。导出要求对象export权限，5000条/表、总量8MiB；超限用管理员完整备份。

真实盘点、供应方凭证和计量口径按G13签认；页面和测试数据不替代实物核对。
