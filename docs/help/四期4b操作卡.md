# 四期4B操作卡：农机、费用与补贴

入口：`/machinery`、`/business`。[设计与交付](../acceptance/4b/实施进度与交付物.md)。本页面只登记和核查事实，不控制机具、不付款、不向政府或省平台申报。

## 农机服务

1. 先登记平台或服务方的账户授权、字段、接口/导出、历史迁移、退出五项书面答复。只能填资料引用，不填密码或令牌。
2. 另一位有审核权限的人核实五项资料及有效期。缺项可以保存草稿，不能当已接入。
3. 从设备台账选择已核机具和定位终端，登记生效时段；同一时段不能重复绑定。解绑保留历史。
4. 建立服务单，填写作业边界、工种、窗口、计划数量和单位。计划量不等于实做量。
5. 有dispatch权限的人员确认人工派单。取消需要原因，不会下发设备停止命令。
6. 分别登记轨迹、作业单、到户确认、抽查。实际数量、单位和确认人保留在原单依据；附件从已有私有原件中选择。
7. 四类证据齐全后，由独立于创建人和证据提交人的审核者验收。仅有轨迹不能验收或作为结算依据。

标准JSON导入最多100行/1MiB。保持同一来源和外部记录号不变，逐行看成功/失败；改正失败行后再提交，成功行不会跨账号重复生成。厂家原始文件须先确认字段并适配，不能把任意CSV当标准JSON。

## 费用与实付

经营明细面向有对象授权的负责人、技术员和管理员；管理员仍按原动作权限配置人员，不能直接代替业务审核。

1. 登记费用类别、计量、金额、付款/收款主体、原凭证和实际发生时间。未知数量或金额留空。
2. 选择来源业务。人工原单可直接登记；关联采购、植保、农机或科研时填写对应记录ID。科研页会列出可用协议/结果ID。
3. 由另一人核实费用。已登记单价和数量时，金额需与按分四舍五入后的乘积一致。
4. 只有实际发生并有凭证的付款才登记。系统不会执行支付，累计实付不得超过当前已核费用。
5. 原付款错误用全额冲销保留旧记录；有付款或有效补贴占用时，先处理依赖再更正费用。

同付款方、收款方和凭证号即使换到另一对象，也不能重复建账。主体别名或不同号码的重复事实仍须人工核对。本台账不代替会计总账、税务申报或跨对象成本分摊。

## 补贴三账

1. 明确购置、报废更新或社会化服务类别，填写具体地区政策、版本、受益主体和期间。
2. 从已核费用中多选关联原单。有效申请会占用这些费用，不能再用于其他类别重复申领。
3. 内部独立复核后，分别登记真实受理、批准、实际到账。没有外部凭证就不要登记为已受理或已到账。
4. 分次到账不超过批准总额；实际退回全额对应原到账。有尚未退回的到账不能直接撤销申请。
5. 外部事实实际日期不清楚时留空，录入时间会单独显示。查到原单日期后使用“更正原外部事实时间”，指向原记录，保留原值和说明，不改变原金额与编号。

软件只能核对已登记资料的状态、数量和重复关系；补贴资格以实际政策及主管部门口径为准。[真实资料交接](../contracts/四期真实资料与接入适配交接.md)

## 失败与导出

读取失败可重试，提交失败保留输入。部分导入不清空草稿；切换账号后旧草稿会被拒绝。每类显示最近200条，汇总从数据库按范围计算。导出需当前export权限，旧链接也会重新核对财务角色。
