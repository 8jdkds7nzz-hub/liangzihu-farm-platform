# 技术员分析与简报操作卡

先审核物种、阶段和专业依据，再启用日历、指标或知识版本。完整率、允许缺测和单位须与实际采样设置对应。

在指标页查看数值、覆盖率、窗口和限制；“暂不能判断”不能当作正常。历史补传重算新增版本，并列天气/农事变化不证明因果。

在知识页检索并打开出处。只有审核且未撤回资料进入新回答；扫描件先识别校核。模型外发关闭或服务失败时，问答页显示程序摘录和缺口。

日报、周报和月报逐条采纳、修改或驳回，写明理由。辅助解释独立追加；模型不能漏掉程序事项或数据限制。转任务只生成草稿，正式派发须在任务页确认具体执行人。

专家分享先确认接收人、事项和截止时间；附件、原文及指标分别授予明确资源范围，不能让对象级授权变成全场浏览。当前分享仅登记受控访问，没有发送短信或其他外部消息。

图片复核未检出不能当作无异常，失败继续人工判断。白天、夜间、雨雾和未告警时段独立抽查；未经现场效果验收，不启用自动过滤。
