# 技术员操作卡

- 先核实测点—对象—批次对应，再填写物种、阶段和阈值适用依据；没有资料的参数留待确认，不用模型推算默认值。
- 规则中的指标单位、比较方向、持续时间、最大间隔、新鲜度和有效期都须核对。管理员配置权限不代替专业审核；参数变化另建版本，未关闭旧事件先核查。
- 现场正常、误报、设备问题与未知分别记录。未知不能当作正常关闭，恢复通知不自动证明处置完成。
- 手持复测与在线值并列；数值不一致先排查方法、时间、单位和校准，不自动取平均。修改记录使用追加更正并说明依据。
- 工单由有派单权限的人明确指定，接单人员提交处理，专业人员复核；系统不自动派单。
- 试运行时记录误报、漏报、断采、认领和处置时间，按依据调整下一版规则。真实现场演练与合成自动测试分开保存。
