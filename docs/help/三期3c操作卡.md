# 三期3C操作卡

三个入口：/protection（植保）、/agronomy（农情影像）、/control-records（控制准备）。

## 植保人员

先核作物、阶段、边界、障碍和敏感邻区；不知道的明确写未核实。每亩剂量由专业人员填写，另一名审核人员确认。处方分享、下载与实际施用分开记录，不因文件发出就记已完成。

作业导入使用标准JSON，每行有稳定externalId、planId及实际记录。查看逐行成功/失败；修正失败行时保留来源和外部号。轨迹点保存时间、坐标、启停、流量及原单位；资料不足时面积为未知，不把疑似覆盖当实际药效。

补作关联原作业及原因、费用。服务商原件先进入私有库，交付清单写清缺项；复查把观察、判断与后续动作分开。

## 影像人员

先导入私有原件，再选择照片分析。绿色比例只是图像特征。候选模型默认关闭，管理员准备本地权重并明确开启实验后才能使用；看到候选分数仍需人工现场判断。

多光谱先在专业工具拼接、配准并做辐射校正，再导入北向WGS84反射率GeoTIFF，填写波段索引、比例/偏移和来源依据。原始DN不能直接用。查看有效像素和无数据；低指数不直接等于缺肥或病害。

农业通知保留原机构、文号、发布日期与适用期，独立审核后使用。流量必须说明实测/率定/模型及单位；开度不能自行换水量。

## 管理员

运行worker:agronomy；未启动时任务停留排队，不能写已完成。模型准备命令为pnpm models:crop-prepare，正常推理只读本地文件。CROP_MODEL_EVALUATION_ENABLED默认0；CAMERA_READS_ENABLED保持既有联调控制。

控制页当前只登记准备和反馈，**真实执行适配器尚未实现**。无论资料填成什么，平台不会下发动作。许可、模式、保护分别核实；外部回执、现场观测和平台登记不能混为一层成功。人工接管注明到场人、装置、条件与实际时间。

现场效能G14、执行适配G15及生产灾备仍须另验，不以工程截图替代。
