## 按设备类型追加的必答项

| 类型 | 填写内容与进入条件 |
|---|---|
| G07监控 | 物理设备与通道、机型固件、签名事件/图片、休眠/抓拍/直播/回放权益、原APP提醒切换与恢复方法 |
| G08航次 | 实装机场与飞行器各自SN、司空区域/版本/项目权限、任务与单次航次对应、实际与计划时间、大文件/自动删除/坐标基准 |
| G15控制 | 实际负载和端口、完整协议、请求幂等/查询、请求/收到/电气动作/机械到位/实际效果、结果未知、停止/手动/断网停复电、既有主站共存、联合试验范围与人员 |
| G16能源 | 采购实装、计量边界/拓扑、原值倍率/净功率正负语义、累计复位溢出、SOC/SOH含义、间隔/补传、关联测点；不得将Ah直接当kWh |
| G17农机 | 账户、字段、导出或接口、历史迁移、退出五项书面答复；机具与终端时段对应、坐标/轨迹精度、启停和实际量语义 |

以上适用项逐项附答复，非适用项写原因。G15/G16及农机实际厂家格式仍须依据资料开发适配，不因填完此表自动获得兼容能力。
