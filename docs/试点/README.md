## 先填写哪几份

1. 范围负责人填01：选定一个对象、一台设备、一笔业务，落实操作、审核和部署责任。
2. 技术员和厂家接口联系人填02，值班/管理员填03，仓管与业务人员填04。三者可以并行；此时不必等待新能源采购和全部厂家答复。
3. 涉及地图三维和实际终端填05；涉及专业规程、模型、科研与指标填06；部署与恢复负责人填07。
4. 每次联调使用08，每日试运行及最后结论使用09；通过证据回填到[G01—G18总表](接入依赖与验收总表.md)的私有副本。

## 如何保存

仓库当前按公开资料管理。本目录仅保存空白模板、公开可描述的状态和脱敏方法；填写后的真实资料不要覆盖这里的模板。

本轮已准备可填写副本目录：`.local/试点接入/20261003_准备/`（在本仓库内，受现有`.local/`忽略规则保护）。包含“资料模板”、总表、“原始资料”和“联调证据”。请复制模板作为每次记录，不覆盖上一次实测。该目录仅提供本机工作副本，不代表加密存储或独立备份已完成；真实资料进入后由负责人纳入受控备份和访问范围。

- 姓名、电话、设备SN、精确坐标、合同、付款单、账号标识及业务原件只留私有副本；公开状态只用去标识代号和必要结论。
- 密码、令牌、私钥、完整连接串、带签名下载链接不填入模板。凭据栏只记密钥存放引用、权限、有效期与保管角色。
- 资料包记录来源、提供人、日期、版本、适用范围和原件SHA-256；私有文件的哈希与路径也只进私有证据索引。
- 日期用带时区的完整时间；业务发生、采样、接收、录入分别记录。未知保留“待核/未提供”并说明责任和阻塞项，不填0或当前时间代替。
- 这9份是人工收集表，没有实现自动批量导入器。专业批准数值和厂家契约核实后再通过既有配置、表单或相应适配录入。
