## 克隆后的准备与使用

在仓库根目录执行一次依赖安装，再按技能工作流选择图种、格式、主题并检查结果：

```sh
npm ci --prefix skills/pretty-mermaid --ignore-scripts --no-audit --no-fund
node skills/pretty-mermaid/scripts/themes.mjs
node skills/pretty-mermaid/scripts/render.mjs --input docs/架构图/监测与核查.mmd --output /tmp/监测与核查.svg --theme github-light
```

支持 SVG、PNG 和终端文本。完整命令及参数见 [SKILL.md](SKILL.md)；图示源文件和成果放到对应文档目录。生成测试输出放在临时目录，不覆盖现有图。
